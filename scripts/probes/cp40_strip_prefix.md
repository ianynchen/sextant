# CP-40 — what `StripPrefix=N` removes from a path

**Version scope.** Measured against **`spring-cloud-gateway-server` 4.3.4 and
`spring-cloud-gateway-server-webflux` 5.0.0**, each version read out of that jar's own
`META-INF/MANIFEST.MF` by `probe.py` before it measures anything, never from a parameter
this harness was handed. Every verdict below bounds to 4.3.4 and 5.0.0 and to nothing wider. That
is the CP-5 failure this convention exists to prevent: eight cells once carried a version the
process never reported. Spring Cloud renamed this module at 5.0, so both sides of the rename
are measured; a rule verified on one side says nothing about the other.

**Why it was measured.** The reactor-linking spec joins a gateway route's literal prefix to
the paths the named service serves, so that `Path=/api/customer/**` in front of
`customers-service`'s `GET /owners/{ownerId}` publishes
`GET /api/customer/owners/{ownerId}`. That composition is only sound if `StripPrefix=N`
removes exactly the prefix being composed — otherwise the published address is one no
request ever takes. `M06` forbids runtime prediction, and this probe is what makes the
difference between composing a prefix and simulating a router.

**What it is NOT.** This measures ONE filter. `RewritePath`, `SetPath` and `PrefixPath`
rewrite paths by other rules and are not measured here, so a route carrying one publishes a
participant-level link and no endpoint link. None appears in the pinned corpora: across
every gateway configuration there, the only path predicate is `Path=` and the only
path-rewriting filter is `StripPrefix=N` — 9 routes of 9.

## The loop, as the bytecode states it

```
path  = request.getURI().getRawPath()
parts = StringUtils.tokenizeToStringArray(path, "/")     // empty tokens discarded
sb    = new StringBuilder("/")
for (i = 0; i < parts.length; i++)
    if (i >= config.getParts()) {                        // keep from index N onward
        if (sb.length() > 1) sb.append('/');
        sb.append(parts[i]);
    }
if (sb.length() > 1 && path.endsWith("/")) sb.append('/');
request.mutate().path(sb.toString())
```

## What this licenses, and the gate it implies

**The composition is exact where `N` equals the predicate prefix's segment count.** A request
to `/api/customer/owners/7` has segments `[api, customer, owners, 7]`; `StripPrefix=2` keeps
from index 2, giving `/owners/7`, which is what `customers-service` serves as
`/owners/{ownerId}`. So the gateway's own address for that route is the prefix followed by
the service's path, and no arithmetic is performed on a per-request basis.

**Where the two numbers disagree, the composition is wrong and must be refused.** With
`Path=/api/customer/**` and `StripPrefix=1` the service receives `/customer/owners/7`, so
either it serves a `/customer` context path — in which case its OWN published path already
carries it — or the route is broken. Neither is the naive composition, and this is the gate
`stitch/gateway.py` applies rather than guessing which.

**Two further facts, measured and not currently relied upon.** A path with fewer than `N`
segments becomes `/`, and repeated slashes collapse because empty tokens are discarded. They
are recorded because the first is the obvious edge case a reader will ask about and the
second would quietly change a path the day a corpus contains `//`.
